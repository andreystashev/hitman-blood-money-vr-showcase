# Gameplay demonstration checklist

State the release version and headset/runtime. Prefer a short continuous example that shows the actual gameplay experience.

Suggested sequence: recenter, look/lean, walk/turn, grab and transfer an item, aim from either hand, support a long gun, reload with A, use a contextual action, inventory and map/briefing.

State which experimental modifiers are enabled and whether they differ from the release defaults. Note visible bugs and performance problems. Check the final video's aspect ratio and game audio; avoid personal desktop content and private paths.
