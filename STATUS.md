# Возможности и ограничения

Состояние на **18 октября 2026 года**, по результатам игровых проверок разработчика.
«Реализовано» означает работу в проверенных сценариях, а не совместимость
всех миссий и моделей. Текущие регрессии имеют приоритет над прежними исправлениями.

| Кастомная перезарядка револьверов, ПП и большого оружия | Добавлена; общий цикл и отдельные модели продолжают дорабатываться |
| Кнопочная перезарядка для всего оружия через настройку | В работе; универсальный вариант ещё не готов |
| Воздушная винтовка | Нужно исправить перезарядку |
| Снайперская винтовка из чемодана | Известный отказ: чемодан не открывается |
| Гильзы пистолетов | Добавлены; отрисовка сквозь тело отмечена как исправленная |
| Сбор оружия и патронов | Доработан: дубликаты оружия переводятся в патроны |
| Несколько однотипных предметов в инвентаре | Проверено, в том числе несколько ножей |

Физическая перезарядка включает действия с магазинами, патронником и механизмами.
Рабочие схемы не означают завершённости всего режима. Остаются магазины,
удобство цикла и частные ошибки оружия. Сейчас магазин нельзя подобрать
без оружия в руке; исправление в работе. Отдельная задача — привлекать NPC
броском магазина по аналогии с монеткой.

## Ближний бой, броски и AI

| Возможность | Состояние |
| --- | --- |
| Удары холодным оружием движением руки | Реализовано; контакт, звук, хват и реакции дорабатываются |
| Удар кулаком при наличии оружия или предмета | Отмечен как реализованный |
| Урон от брошенного магазина или оружия | Отмечен как реализованный |
| Бросок и извлечение ножей и других инструментов из тел | Проверено; указанные проблемы исправлены |
| Шокер и удавка | Работа с ними отмечена как выполненная; универсальная свободная схема жестов не заявляется |
| Добивания и пересечения текстур | Нужна проверка по типам оружия |
| Обнаружение при физических действиях | Нужна проверка свидетелей, скрытых атак и связи нападения с игроком |
| Тревога при бросках | Открытая проблема: ожидаемый статус тревоги не появляется |
| Статистика добиваний | Ещё не проверено, засчитываются ли физические удары оружием как соответствующие добивания |

В предыдущих тестах секатор давал хорошую основу реакций; у ножа и молотка
оставались вопросы направления контакта, у биты — естественности анимации.
Звук и хват отдельных моделей остаются задачами.

Для анимации удавки результат отмечен как нормальный, агент виден; у шприцев
агент скрыт. Нож, шокер, бита и секатор остаются в списке проверки анимаций
и текстур: согласованность отображения тела пока не считается подтверждённой.

## Производительность, совместимость и выпуск

Ранее исправлялась причина периодических задержек при поиске предметов.
Общая производительность остаётся открытой задачей: нужно профилировать
отрисовку и исследовать уменьшение частоты кадров вдвое. Текущий стереопуть
использует последовательные игровые кадры; требуется сравнить игровой FPS,
частоту стереопары и фактический вывод в шлем. Готовый прирост не заявляется.

Основная проверяемая конфигурация — **Windows, оригинальная PC-игра,
Meta Quest 3S, Quest Link / Air Link**. Другие EXE и выпуски игры ещё нужно
проверить; универсальная совместимость и другие гарнитуры не подтверждены.

Установщик, новая видеодемонстрация, чистка кода и подготовка выпуска остаются
задачами. Этот публичный репозиторий содержит описание разработки; исходники
мода и готовая публичная сборка здесь не размещены. Дата выпуска не объявлена.
