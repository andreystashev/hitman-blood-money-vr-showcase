# Возможности и ограничения

Состояние разработки на **17 октября 2026 года**.

## Камера и управление

| Возможность | Текущее состояние |
| --- | --- |
| Изображение в VR, положение и поворот головы | Реализовано |
| Первое лицо, наклоны и центрирование | Реализовано |
| Передвижение и поворот контроллерами | Реализовано |
| Физическое приседание | Реализовано; продолжается настройка положения тела |
| Отслеживаемые руки | Реализовано; дорабатываются локти, досягаемость и вид в зеркалах |
| Штатные сцены, перелезания и Requiem | Добавлена адаптация для VR; проверка разных миссий продолжается |

## Оружие и предметы

| Возможность | Текущее состояние |
| --- | --- |
| Наведение и стрельба контроллерами | Реализовано для обеих рук |
| Независимое наведение двух пистолетов | Реализовано |
| Подбор, удержание, броски и передача предметов | Реализовано; остаются отдельные ошибки столкновений |
| Поддержка длинного оружия второй рукой | Реализовано; хват цевья ещё требует настройки для разных моделей |
| Включение прицела у глаза | Реализовано; исправлены левое прицеливание и выход из увеличения |
| Живое изображение внутри линзы | Не завершено; сейчас основное прицеливание использует штатное увеличение игры |
| Кнопочная перезарядка | Реализовано; в этом режиме A перезаряжает правое оружие, левое переносится вправо |
| Физическая перезарядка | Реализован экспериментальный режим; требует дальнейшей доводки |

Физическая перезарядка включает извлечение, удержание, вставку и повторный подбор магазинов, работу с патронником и затвором. Добавлены схемы зарядки револьверов, дробовиков и винтовок с ручным циклом. Для части оружия используются родные модели магазинов, движения механизмов и звуки.

Остаются настройка разных моделей, обработка прерываний и смены рук, сохранение промежуточного состояния, дополнительные звуки и вибрация. Полный физический цикл двух пистолетов ещё требует доработки.

## NPC и окружение

| Возможность | Текущее состояние |
| --- | --- |
| Автоматическое выпадение вещей NPC | Реализовано |
| Захват и перемещение тел | Реализовано за кисти и стопы; улучшена работа с уснувшей физикой |
| Переодевание и сокрытие тел | Доступны через штатные действия игры |
| Удары холодным оружием | Реализован экспериментальный режим; геометрия контакта ещё приближённая |
| Захват живого заложника | Эксперимент: дорабатываются движение, освобождение и реакции AI |
| Захват декора | Поддерживается часть физических объектов; произвольный статичный декор недоступен |
| Удавка | Доступно штатное действие; свободный двуручный жест ещё не реализован |

На отдельных поверхностях предметы могут отскакивать или проваливаться. Двуручный хват и размещение кистей также остаются среди основных задач.

## Интерфейс

| Возможность | Текущее состояние |
| --- | --- |
| Меню и инвентарь с контроллеров | Реализовано |
| Выбор предмета GRIP в нужную руку | Реализовано |
| Здоровье, тревога, названия предметов и патроны в инвентаре | Добавлено; продолжается настройка удобства и читаемости |
| Подсказки кнопок у объектов | Добавлено; надписи на английском |
| Обводка доступного предмета | Реализовано |
| Действия у дверей, одежды и мест сокрытия | Добавлены контекстные подсказки; размещение уточняется |
| Пространственное колесо инвентаря | В планах; пока используется адаптированное штатное меню |

Показатели состояния размещены в инвентаре, поэтому для их просмотра не нужен отдельный предмет в руке.

## Плавность и совместимость

Исправлены конфликт запуска VR и причина периодических задержек при поиске предметов на больших уровнях. Проверка плавности на разных миссиях продолжается.

Стереоизображение пока использует последовательные игровые кадры: при быстрых движениях возможны временные различия между глазами. Улучшение согласованности стереопары и снижение задержек передачи изображения остаются в работе.

Основная конфигурация — **Windows, Meta Quest 3S и Quest Link / Air Link**. Требуется поддержанная версия оригинальной PC-игры. Совместимость всех миссий, выпусков игры и других гарнитур пока не проверена.
