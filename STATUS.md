# Состояние проекта

Обновлено: **13 октября 2026 года**.

Этот список отделяет реализацию, проверку в настоящей игре и планы. Автоматический тест не подтверждает комфорт, точность положения рук или прохождение миссий в шлеме. Название внутренней ветки «stable» также не является подтверждением стабильного релиза.

## Текущая короткая демонстрация

По сообщению автора, в записанном ролике показаны только 6DoF-оружие, взятие пистолетов в обе руки и перезарядка правого пистолета по кнопке. Перезарядка левой руки и физическая перезарядка не демонстрируются. Остальная таблица описывает состояние разработки и задачи проверки, а не содержание ролика.

## Основная версия для проверки

| Возможность | Что есть | Что подтверждено и что проверить |
| --- | --- | --- |
| Изображение в шлеме и стерео | Реализовано | Подтверждено в предыдущих игровых сессиях; текущий кандидат требует повторной проверки |
| Движение головы и первое лицо | Реализовано | Работа камеры подтверждалась ранее; проверить смещение, центрирование и серию выстрелов |
| Отслеживаемые руки | Реализован IK рук | Проверить совпадение с контроллерами, хват и переплетение рук |
| Наведение оружия | Реализовано для обеих рук | Направление подтверждалось пользователем; проверить попадания на близкой и дальней дистанции |
| Два пистолета | Независимое наведение и ввод | Проверить стрельбу каждой рукой, одновременные выстрелы и перезарядку без потери второго хвата |
| Простая перезарядка | В текущем ролике — только правый пистолет по кнопке | Перезарядка слева не показана; её работа требует отдельной проверки |
| Перемещение | Управление контроллерами | Проверить движение, поворот, взаимодействие с камерой и фокус окна |
| Меню и инвентарь | Штатные экраны с вводом контроллеров | Проверить главное меню, паузу, выбор оружия и возврат в игру |
| Захват, бросок, хранение | Реализованы | Сообщалось о сбоях; проверить повторный захват и отпускание экипированного оружия |
| Передача между руками | Реализована | Проверить сохранение предмета и последующий выстрел |
| Поддержка длинного оружия | Реализована | Активация, наведение и поза поддерживающей кисти требуют проверки |
| Оптика | Штатный полноэкранный zoom | Проверить вход, выход и размещение окуляра; живой вид внутри линзы отсутствует |
| Загрузка миссий и сохранений | Есть защита жизненного цикла объектов | Ранее загрузки проверялись; для текущего кандидата нужны повторные проверки нескольких миссий |

## Экспериментальные механики

| Возможность | Состояние |
| --- | --- |
| Физические магазины | Реализованы жесты извлечения, взятия, вставки и досылания; выключены в основной конфигурации |
| Револьверы | Добавлены открытие/закрытие барабана и поштучная загрузка; нужна проверка моделей и жестов в VR |
| Дробовики | Добавлены поштучная загрузка, дозарядка и ручной цикл; нужна проверка в VR |
| Ручные винтовки и дротики | Добавлены соответствующие схемы зарядки и цикла; нужна проверка экземпляров оружия |
| Физическая перезарядка двух пистолетов | Пока используется простая кнопочная перезарядка |
| Приседание тела | Экспериментальная функция выключена по умолчанию; физическая высота взгляда отслеживается |
| Полное тело | Экспериментальное отображение выключено по умолчанию; требуется проверка камеры и геометрии тела |

## Ещё предстоит реализовать или завершить

- Живое изображение внутри линзы прицела.
- Стереопара из одного состояния игры.
- Передача изображения без текущего копирования через CPU.
- Видимые механические анимации физической перезарядки, гильзы, звуки и вибрация.
- Сохранение промежуточного состояния физической перезарядки.
- VR-инвентарь с удобным выбором оружия и предметов.
- Двуручное взаимодействие с удавкой.
- Столкновения рук с NPC и действия, определяемые физическими жестами.

## Как обновлять статус

После каждой игровой проверки фиксируются версия сборки, шлем, подключение, миссия, результат и ссылка на видео либо описание воспроизведения. Формулировка «проверено в игре» относится только к указанной конфигурации и сценарию. Обнаруженная проблема сохраняется в списке до повторной проверки исправления.
