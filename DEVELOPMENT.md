# Development

Public releases prioritize a conservative configuration so reports from different testers can be compared. This repository contains documentation, releases and feedback; development source is maintained separately.

To help, test the default profile with separate saves. Include the mission, outfit, weapon/upgrades, runtime and exact release version in reports. Distinguish reproducible bugs from feature requests. Attach the optional reviewed diagnostic report rather than private files.

See [STATUS.md](STATUS.md), [ROADMAP.md](ROADMAP.md) and [CHANGELOG.md](CHANGELOG.md).
